# App1 - Colocated Sparkplug Client (container)

## Building

Built automatically by `docker compose up --build` from [`../`](../), using
`../` (not this directory) as the build context - the `Dockerfile` needs to
reach [`../vendor/`](../vendor/README.md) too. To build just this image
directly:

```bash
cd Library
docker build -t app1-colocated -f app1-colocated/Dockerfile .
```

## Config

App1 has no config directory. Its XRT component config is compiled into
`spg_demo` as C string constants in
[`deployment_config.h`](deployment_config.h), and handed to XRT by a custom
config loader in `spg_demo.c`.

All of it is defined in [`deployment.pkl`](deployment.pkl):

| Output | How it gets there |
|---|---|
| Component config | **FOR NOW:** kept in step with `deployment.pkl` by hand in `deployment_config.h`, since the XRT Pkl schema can't render C strings yet |
| `deployment/state/*/devices.json`, `schedules.json` | Generated by `../generate-pkl-config.sh app1-colocated`. Don't edit them by hand |

The BACnet device profiles under `deployment/state/*/profiles/` are still
plain JSON.
